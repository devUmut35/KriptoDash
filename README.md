# KriptoDash

KriptoDash, React ile geliştirilmiş responsive bir kripto portföy dashboard uygulamasıdır. Uygulama; kripto para verilerini görsel olarak sunmak, portföy durumunu takip etmek ve kullanıcıya modern bir dashboard deneyimi sağlamak amacıyla hazırlanmıştır.

## Özellikler

- Responsive arayüz tasarımı
- Açık/koyu tema modu
- Kripto portföy dashboard yapısı
- Grafiklerle veri görselleştirme
- Bootstrap grid sistemi
- SCSS ile düzenlenmiş stil yapısı
- Animasyonlar ve geçiş efektleri
- Modern kart tabanlı kullanıcı arayüzü
- SEO uyumlu temel meta etiketleri
- Cross-browser uyumlu yapı

## Kullanılan Teknolojiler

- React
- JavaScript
- HTML5
- CSS3
- SCSS / Sass
- Bootstrap
- Chart.js

## Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak için repoyu klonlayın:

```bash
git clone https://github.com/kullanici-adi/repo-adi.git
```

Proje klasörüne girin:

```bash
cd repo-adi
```

Gerekli paketleri yükleyin:

```bash
npm install
```

Projeyi geliştirme ortamında başlatın:

```bash
npm start
```

Uygulama varsayılan olarak şu adreste çalışır:

```txt
http://localhost:3000
```

## Build Alma

Projeyi production ortamı için derlemek isterseniz:

```bash
npm run build
```

Bu komut, optimize edilmiş çıktıları `build/` klasörü içerisine oluşturur.

## Tema Modu

Projede açık ve koyu tema desteği bulunmaktadır. Kullanıcı arayüz üzerinden tema değişimi yapabilir. Bu özellik, kullanıcı deneyimini artırmak ve farklı kullanım tercihlerine uyum sağlamak amacıyla eklenmiştir.

## Responsive Tasarım

KriptoDash farklı ekran boyutlarına uyum sağlayacak şekilde geliştirilmiştir. Masaüstü, tablet ve mobil ekranlarda kullanılabilir bir arayüz sunar.

## Grafik Kullanımı

Projede kripto para ve portföy verilerinin daha anlaşılır gösterilebilmesi için grafik yapıları kullanılmıştır. Grafikler sayesinde kullanıcılar verileri görsel olarak daha kolay analiz edebilir.

## Performans ve SEO

Proje hazırlanırken performans, erişilebilirlik ve SEO kriterleri dikkate alınmıştır. Temel meta etiketleri yapılandırılmış, arayüz performanslı ve sade bir yapıda geliştirilmiştir.
